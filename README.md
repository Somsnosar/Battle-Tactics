# Battle-Tactics
A FTK2(For the King 2) mod allowing for the tactical positioning of party members &amp; pets via their portraits before battle.

# Installation
Guide to installing the mod! (Hoping to get the game on r2modman but for now, it's this)
## Download [BepInEx](https://github.com/BepInEx/BepInEx/releases)
<img width="1791" height="916" alt="image" src="https://github.com/user-attachments/assets/3fb53a96-9654-4840-90d0-acc94d4c8bc1" />
Scroll down to assets, and download the version destined for your device.
Once downloaded, unzip in any old directory then place the contents into "~/For The King II"
<img width="1791" height="1010" alt="image" src="https://github.com/user-attachments/assets/1fad210d-ccf8-44f5-9c4a-4eb9b04c1fa5" />
Now you can download the mod!<br>
<img width="1604" height="915" alt="image" src="https://github.com/user-attachments/assets/12321e8c-230d-4518-8c1a-e63931aecd7c" />
Download the Battle-Tactics.dll from this page in the releases section on the right, and drag that into "~/For The King II/BepInEx/plugins/Battle-Tactics".<br>
There might not be a plugins folder there, so make one! Then everyone will have to make the next "Battle-Tactics" folder within that.
